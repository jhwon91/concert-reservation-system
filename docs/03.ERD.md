# ERD

```mermaid
erDiagram
    users {
        UUID user_id PK "사용자 고유 식별자"
        VARCHAR email UK "이메일 (로그인 식별자)"
        VARCHAR name "사용자 이름"
        VARCHAR phone "연락처"
        TIMESTAMP created_at "생성 일시"
        TIMESTAMP updated_at "수정 일시"
    }

    user_points {
        UUID user_point_id PK "포인트 고유 식별자"
        UUID user_id FK "사용자 식별자 (unique)"
        DECIMAL balance "현재 보유 잔액"
        BIGINT version "낙관적 잠금 버전"
        TIMESTAMP created_at "생성 일시"
        TIMESTAMP updated_at "수정 일시"
    }

    point_transactions {
        UUID point_transaction_id PK "거래 고유 식별자"
        UUID user_id FK "사용자 식별자"
        DECIMAL amount "거래 금액 (양수)"
        DECIMAL balance_after "거래 후 잔액"
        VARCHAR type "거래 유형 (CHARGE/USE)"
        UUID related_id "연관 ID (결제 ID 등, nullable)"
        TIMESTAMP created_at "거래 발생 일시"
    }

    queue_tokens {
        UUID queue_token_id PK "토큰 고유 식별자"
        UUID user_id FK "사용자 식별자"
        TEXT token_value UK "토큰 값 (UUID 문자열)"
        INT queue_position "대기열 순번 (ACTIVE 시 0)"
        VARCHAR status "토큰 상태 (WAITING/ACTIVE/EXPIRED)"
        INT estimated_wait_sec "예상 대기 시간(초)"
        TIMESTAMP issued_at "토큰 발급 일시"
        TIMESTAMP activated_at "토큰 활성화 일시 (nullable)"
        TIMESTAMP expires_at "토큰 만료 일시 (활성화 후 10분)"
        TIMESTAMP created_at "생성 일시"
        TIMESTAMP updated_at "수정 일시"
    }

    concerts {
        UUID concert_id PK "콘서트 고유 식별자"
        VARCHAR name "콘서트 이름"
        VARCHAR venue "공연 장소"
        TEXT description "콘서트 설명"
        TIMESTAMP created_at "생성 일시"
        TIMESTAMP updated_at "수정 일시"
    }

    concert_dates {
        UUID concert_date_id PK "공연 일정 고유 식별자"
        UUID concert_id FK "콘서트 식별자"
        DATE date "공연 날짜"
        INT total_seats "총 좌석 수 (기본 50)"
        INT available_seats "예약 가능한 잔여 좌석 수"
        TIMESTAMP created_at "생성 일시"
        TIMESTAMP updated_at "수정 일시"
    }

    seats {
        UUID seat_id PK "좌석 고유 식별자"
        UUID concert_date_id FK "공연 일정 식별자"
        INT seat_number "좌석 번호 (1~50)"
        VARCHAR status "좌석 상태 (AVAILABLE/RESERVED/OCCUPIED)"
        DECIMAL price_amount "좌석 가격"
        BIGINT version "낙관적 잠금 버전"
        TIMESTAMP created_at "생성 일시"
        TIMESTAMP updated_at "수정 일시"
    }

    reservations {
        UUID reservation_id PK "예약 고유 식별자"
        UUID user_id FK "사용자 식별자"
        UUID seat_id FK "좌석 식별자"
        UUID concert_date_id FK "공연 일정 식별자"
        TEXT token_value "예약 시 사용한 대기열 토큰 값"
        VARCHAR status "예약 상태 (PENDING/CONFIRMED/CANCELLED)"
        TIMESTAMP reserved_at "예약 요청 일시"
        TIMESTAMP confirmed_at "결제 완료 일시 (nullable)"
        TIMESTAMP expires_at "임시 점유 만료 일시 (예약 후 5분)"
        TIMESTAMP created_at "생성 일시"
        TIMESTAMP updated_at "수정 일시"
    }

    payments {
        UUID payment_id PK "결제 고유 식별자"
        UUID reservation_id FK "예약 식별자"
        UUID user_id FK "사용자 식별자"
        DECIMAL amount "결제 금액"
        VARCHAR payment_method "결제 수단 (POINT)"
        VARCHAR status "결제 상태 (PENDING/COMPLETED/FAILED)"
        TIMESTAMP created_at "결제 시도 일시"
        TIMESTAMP completed_at "결제 완료 일시 (nullable)"
    }

    users ||--|| user_points : "1:1"
    users ||--o{ point_transactions : ""
    users ||--o{ reservations : ""

    concerts ||--o{ concert_dates : ""
    concert_dates ||--o{ seats : ""

    reservations ||--|| seats : ""
    reservations ||--|| payments : ""
```

---

## 주요 제약 조건

| 테이블 | 제약 |
|--------|------|
| seats | seat_number BETWEEN 1 AND 50 |
| user_points | balance >= 0 |
| concert_dates | available_seats >= 0 AND available_seats <= total_seats |
| queue_tokens | status IN ('WAITING', 'ACTIVE', 'EXPIRED') |
| reservations | status IN ('PENDING', 'CONFIRMED', 'CANCELLED') |
| payments | amount > 0 |

## 주요 인덱스

| 테이블 | 인덱스 | 목적 |
|--------|--------|------|
| queue_tokens | (status, queue_position) | 스케줄러 활성화 쿼리 |
| queue_tokens | (expires_at) | 만료 처리 쿼리 |
| queue_tokens | (token_value) | 토큰 검증 |
| seats | (concert_date_id, status) | 가용 좌석 조회 |
| reservations | (expires_at, status) | 만료 예약 스케줄러 |
| reservations | (user_id) | 사용자별 예약 조회 |
| point_transactions | (user_id, created_at) | 거래 내역 조회 |

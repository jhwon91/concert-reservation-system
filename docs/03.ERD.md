# ERD

```mermaid
erDiagram
    users {
        UUID id PK
        VARCHAR email UK
        VARCHAR name
        VARCHAR phone
        TIMESTAMP created_at
        TIMESTAMP updated_at
    }

    user_points {
        BIGINT point_id PK
        UUID user_id FK "unique"
        DECIMAL balance
        BIGINT version "낙관적 잠금"
        TIMESTAMP created_at
        TIMESTAMP updated_at
    }

    point_transactions {
        UUID transaction_id PK
        UUID user_id FK
        DECIMAL amount "차감은 음수"
        DECIMAL balance_after
        VARCHAR type "CHARGE/USE/REFUND"
        VARCHAR description
        VARCHAR related_id "결제 ID 등"
        TIMESTAMP created_at
    }

    queue_tokens {
        UUID id PK
        UUID user_id
        TEXT token_value UK "unique"
        INT queue_position
        VARCHAR status "WAITING/ACTIVE/EXPIRED"
        INT estimated_wait_sec
        TIMESTAMP issued_at
        TIMESTAMP activated_at
        TIMESTAMP expires_at
        TIMESTAMP created_at
        TIMESTAMP updated_at
    }

    concerts {
        UUID id PK
        VARCHAR name
        VARCHAR venue
        TEXT description
        TIMESTAMP created_at
        TIMESTAMP updated_at
    }

    concert_dates {
        UUID id PK
        UUID concert_id FK
        DATE date
        INT total_seats "기본 50"
        INT available_seats
        TIMESTAMP created_at
        TIMESTAMP updated_at
    }

    seats {
        UUID id PK
        UUID concert_date_id FK
        INT seat_number "1~50"
        VARCHAR status "AVAILABLE/RESERVED/OCCUPIED"
        DECIMAL price_amount
        VARCHAR price_currency "KRW"
        BIGINT version "낙관적 잠금"
        TIMESTAMP created_at
        TIMESTAMP updated_at
    }

    reservations {
        UUID id PK
        UUID user_id FK
        UUID seat_id FK
        UUID concert_date_id FK
        TEXT token_value
        VARCHAR status "PENDING/CONFIRMED/CANCELLED"
        TIMESTAMP reserved_at
        TIMESTAMP confirmed_at
        TIMESTAMP expires_at "예약 후 5분"
        TIMESTAMP created_at
        TIMESTAMP updated_at
    }

    payments {
        VARCHAR payment_id PK
        UUID reservation_id FK
        UUID user_id FK
        DECIMAL amount
        VARCHAR currency "KRW"
        VARCHAR payment_method "POINT"
        VARCHAR status "PENDING/COMPLETED/FAILED"
        TIMESTAMP created_at
        TIMESTAMP completed_at
    }

    users ||--|| user_points : "1:1"
    users ||--o{ point_transactions : ""
    users ||--o{ reservations : ""

    concerts ||--o{ concert_dates : ""
    concert_dates ||--o{ seats : ""

    reservations ||--|| seats : ""
    reservations ||--|| payments : ""
```

---

## 주요 제약 조건

| 테이블 | 제약 |
|--------|------|
| seats | seat_number BETWEEN 1 AND 50 |
| user_points | balance >= 0 |
| concert_dates | available_seats >= 0 AND available_seats <= total_seats |
| queue_tokens | status IN ('WAITING', 'ACTIVE', 'EXPIRED') |
| reservations | status IN ('PENDING', 'CONFIRMED', 'CANCELLED') |
| payments | amount > 0 |

## 주요 인덱스

| 테이블 | 인덱스 | 목적 |
|--------|--------|------|
| queue_tokens | (status, queue_position) | 스케줄러 활성화 쿼리 |
| queue_tokens | (expires_at) | 만료 처리 쿼리 |
| queue_tokens | (token_value) | 토큰 검증 |
| seats | (concert_date_id, status) | 가용 좌석 조회 |
| reservations | (expires_at, status) | 만료 예약 스케줄러 |
| reservations | (user_id) | 사용자별 예약 조회 |
| point_transactions | (user_id, created_at) | 거래 내역 조회 |
